Nedolauncher

A Minecraft: Java Edition launcher for communities that play together on their own servers.

Status: about 90% done, in private testing. It will be released publicly as soon as everything works end to end.

Most launchers are made for one person managing their own instances. Nedolauncher is made for a group: an admin puts a modpack together once, and every player gets exactly the same game - the same Minecraft version, mod loader build, mods, configs and Java - without setting anything up by hand.

What it does

  • Server-managed modpacks. Modpacks live on the community's own server. Players pick one and press play; the launcher downloads only what they don't have yet and checks every file by its hash. When the admin updates a modpack, players get the update on the next launch.
  • Optional client mods. The admin marks mods as optional (minimaps, shaders and so on), and each player turns them on or off for themselves.
  • Java per Minecraft version. The right Java runtime is picked and downloaded for each game version, so old Forge builds and new releases both just work.
  • Vanilla, Forge, NeoForge and Fabric, from Minecraft 1.7.10 to the latest releases.
  • One search for Modrinth and CurseForge. Mods, resource packs, shader packs and ready-made modpacks from both sites in one list, with each project's page, gallery and description. Required dependencies are installed together with a mod.
  • Own instances too. Players can still make their own instances and add whatever they like.

Respecting mod authors

  • Every project is shown with its authors and links back to its page on CurseForge or Modrinth.
  • Files whose authors don't allow distribution through third-party apps are never downloaded by the launcher; the player is pointed to the project's page instead.
  • The launcher is free and has no ads or paid features.
